# Reading photos

Generated by `scripts/eval_transcription.py`. Each of the 16 example attempts (8 with a planted error, 8 correct) was rendered as a notebook page by `scripts/render_photos.js`, read by `qwen/qwen3.8-27b`, and reviewed by `openai/gpt-oss-120b` with the course, once from the typed text and once from the transcription.

The pages are typeset maths in a handwriting font, much easier than real handwriting. This checks that transcription keeps the student's errors and line breaks; it does not measure reading real handwriting, which needs real photos.

Lines count as identical when they match up to spacing and notation (LaTeX or Unicode, `\sin` or `sin`).

| | Result |
|---|---|
| Same number of lines as typed | 15 / 16 |
| Lines read identically | 58 / 60 |
| Planted error line read identically | 7 / 8 |
| Review right, typed attempt | 15 / 16 |
| Review right, photo attempt | 14 / 16 |

A review is right when it names the planted line, or finds nothing in a correct attempt. With 16 attempts these are checks, not estimates.
