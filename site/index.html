Math-Hinter

Il lit une copie de maths, trouve la première ligne fausse et donne un indice sans donner la réponse. Il s'appuie sur le cours et peut vérifier un calcul avec SymPy.

Code source Rapport d'évaluation

Démonstration

Vérifier une égalité

Le même vérificateur que l'agent, exécuté dans votre navigateur. Il répond « vérifié » seulement si les deux membres sont égaux pour toutes les valeurs des lettres, et « réfuté » seulement pour deux nombres différents. Sinon il dit « non vérifiable » plutôt que de deviner.

=

Exemples :

Une lettre devant une parenthèse se lit comme une fonction : écrivez x\cdot(x+2) pour un produit. Le premier calcul charge Python (environ 15 Mo).
